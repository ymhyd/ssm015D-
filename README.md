前端Nodejs：16+

浏览器：谷歌浏览器

### 五、项目介绍
项目编号：ssm015D

基于SSM的井冈山大学兼职系统面向学生、企业、管理员，提供公告资讯查看、兼职岗位信息查看、兼职岗位信息申请、学生简历管理、岗位申请管理、学生评价查看、岗位邀请查看等功能，实现各角色在系统中的实际业务协作。

角色：学生、企业、管理员

学生功能：前台登录注册与个人中心维护、公告资讯浏览、兼职岗位浏览收藏申请、学生简历维护下载、岗位申请维护下载、岗位邀请查看、学生评价查看。

企业功能：后台登录注册、学生简历管理、兼职岗位管理、岗位类型管理、岗位申请审核、岗位邀请管理、学生评价管理。

管理员功能：后台登录、功能表管理、学生企业管理、学生简历管理、兼职岗位管理、岗位申请管理、学生评价管理、岗位邀请管理。
